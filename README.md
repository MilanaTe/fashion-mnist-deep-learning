Fashion-MNIST Deep Learning Classification

This project demonstrates a basic deep learning image classification workflow using PyTorch and the Fashion-MNIST dataset.

 
- Fashion-MNIST image classification
- Fully connected neural network
- PyTorch training pipeline
- Cross-entropy loss
- Adam optimizer
- Model accuracy evaluation
- Training loss visualization
- Prediction examples

Dataset:

Fashion-MNIST contains 28x28 grayscale images from 10 clothing categories.

Technologies:
- Python
- PyTorch
- torchvision
- NumPy
- Matplotlib
